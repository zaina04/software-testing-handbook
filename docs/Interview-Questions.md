# ISTQB Foundation Level Interview Questions

This document contains common interview questions based on the ISTQB Foundation Level syllabus. Try answering them yourself before checking your notes.

---

# Fundamentals of Testing

1. What is software testing?
2. What are the main objectives of software testing?
3. Can testing prove that software is bug-free? Why or why not?
4. What is the difference between testing and debugging?
5. Explain the difference between Quality Assurance (QA) and Quality Control (QC).
6. What is the difference between an error, defect, and failure?
7. What are the Seven Testing Principles?
8. Why is exhaustive testing impossible?
9. Why should testing start early in the SDLC?
10. What skills make a good software tester?

# Scenario-Based Questions

59. You discover a critical bug one day before release. What would you do?

60. A developer says, "It works on my machine." How would you respond as a tester?

61. A login page accepts empty usernames and passwords. What would you report?

62. Which testing technique would you use to test an age field that accepts values from 18 to 60?

63. A recent software update caused an existing feature to stop working. What type of testing would detect this?

64. During a code review, you notice several coding standard violations without running the application. What type of testing are you performing?

65. A project has limited time for testing. Which areas should you test first?

66. A customer confirms the software meets all business requirements. Which test level has been completed?

67. Which testing technique would you use for an ATM or traffic light system?

68. Why is communication between developers and testers important?
